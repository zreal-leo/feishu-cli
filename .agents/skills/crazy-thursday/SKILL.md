# 疯狂星期四

写出一条能直接发到朋友群或朋友圈的原创段子：先让读者进入一种叙事，再让吃炸鸡这件小事突然接管剧情。

## 理解笑点

核心是**预期错位**。读者以为正在读失恋倾诉、身份揭秘、重大通知或逆袭故事，结尾却发现所有铺垫只为一顿肯德基。

“V我50”是常见收口，但不是唯一笑点。也可以靠重复、排比、文字拆解或读者已经猜到结尾的自嘲成立；不要把所有文案写成“普通句子 + 今天疯狂星期四 + V我50”。

需要查看网络样本、分析依据或具体流派时，读 [来源与写法分析](references/source-analysis.md)。需要校准节奏或找不同结构时，读 [原创示例](references/examples.md)。两份参考按需读取。

## 接住用户的要求

- 优先采用用户指定的主题、对象、语气、长度和结尾，保留指定文案及关键词。
- 需求明确就直接写；只在缺少的信息会明显改变文案时提问。
- 创作或改写时，每次只输出一条文案；即使用户要求多条，也只给一条，不编号、不提供备选版本。未指定长度时约 80–160 个汉字，适合朋友群，结尾自然落到肯德基、疯狂星期四或“V我50”。
- 写短句时允许开门见山，不强塞长篇故事。用户要求长篇时，用细节和情节推进扩写，不靠重复情绪凑字数。
- 用户只要成品，就只给成品；不要在正文后解释笑点，或加“希望你喜欢”等客套话。

## 选择结构

| 写法 | 铺垫的预期 | 转折如何发生 |
| --- | --- | --- |
| 苦情反转 | 分手、落单、等待消息，需要安慰 | 把看似情感上的缺口落到一顿饭 |
| 爽文觉醒 | 重生、系统、末日、逆袭，事情很大 | 揭晓宏大行动只为解决吃鸡预算 |
| 身份揭晓 | 隐藏身份、失散关系、神秘使命 | 让身份或使命在最后成为请客理由 |
| 倒计时悬疑 | 紧急时限、层层递进，答案即将揭晓 | 把紧迫感落到饭点或周四 |
| 排比递进 | 多次拒绝、控诉、比较，语气越来越重 | 最后一项突然暴露真实诉求 |
| 一本正经 | 仿通知、报告、评审，措辞郑重 | 用严肃口吻解释微小的饥饿问题 |
| 反套路自嘲 | 作者和读者都知道“又来这一套” | 把写段子、识破段子本身变成求饭理由 |
| 文字机关 | 重复、拆字、藏头、断句，形式先抓人 | 让字符或节奏直接揭晓疯四梗 |

每次以一种结构为主，让场景和收口服务于当前主题。主题只是素材：职场既能写成苦情，也能写成报告或爽文。

## 把铺垫写到收口上

1. 先想最后一拍：读者刚建立的预期将被哪件小事打断？
2. 倒推开场和一两个具体细节，例如未读消息、会议纪要、地铁末班车。细节应支持剧情，至少一个能在结尾被重新理解。
3. 让语气暂时可信。悬疑就认真吊胃口，苦情就平静倾诉；不要一路堆“震惊”“惊天秘密”等空词。
4. 常规反转把肯德基、周四、转账等信号留到后段，减少提前泄底；反套路和短句可以直接暴露目的。
5. 用一句话完成降落。转折可以突然，但前面的情绪、道具或词语要能接上；收口之后立刻停。
6. 默读删掉解释笑点、重复信息和生硬过渡。读起来像一个人在聊天，不像列出了写作模板。

可以使用狗血、荒诞和夸张人设。学习网络样本的结构，重新设计人物、细节和转折，不复制整段故事或只替换几个词。用户给出原文时，在授权的改写目标内保留其关键内容。

## 按任务交付

- **创作**：只输出一条可直接复制的成品，不编号、不加剧透式风格标题、不提供备选版本。
- **改写**：保留用户指定的素材，修好铺垫、节奏和转折，只给一条改写后的成品。只有用户要求对比时才附修改说明。
- **拆解**：指出开场建立的预期、推动阅读的细节、转折位置和收口机制；引用简短片段，其他内容概述，不把分析当成创作结果。

## 成品检查

- 去掉最后一句，前文是否仍像一段能引人读下去的内容？短句和形式梗则检查节奏或文字机关是否独立成立。
- 结尾是否改变了前文的意义，或完成了形式梗，而不只是贴上品牌名？
- 是否只输出了一条文案，没有编号或备选版本？是否过早泄底、铺垫过长、转折后还在解释？
- 若用了藏头、拆字或指定字数，实际核对字符；无法自然成立时换一种写法。
- “V我50”是玩梗金额，不代表套餐价格。通用段子不需要查询菜单；涉及真实日期、当期价格或活动规则时再核实，不将旧样本的促销信息当成现行活动。
- 仿公告可以写成明显荒诞的个人通知，不冒充真实官方优惠或真实求助。成品不附真实收款账号或二维码。

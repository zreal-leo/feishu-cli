# 来源与写法分析

## 从样本归纳出的创作判断

- **铺垫负责建立预期。** 大事件、私人情绪或正式措辞越有具体内容，结尾的小诉求越能改变前文的读法。
- **反转可以靠语义，也可以靠形式。** 故事类让读者猜错目的；字形、重复和断句类让读者在阅读中看见答案。
- **熟悉结尾不等于失去笑点。** 反套路可以利用读者的识破感；这时新意来自作者如何承认或绕回目的。
- **传播成品与研究报告不同。** 群聊文案应能直接复制，通常不附解说；来源和结构分析留在参考文件。
- **长度应服务机制。** 倒计时或问答可以很短，轮回故事需要情节推进。不要把每条都拉长，也不要只在普通句子后补一个固定口号。

一本正经的报告、公文及职场改写是基于上述预期错位机制的创作扩展；示例中的设定并非对某个网络原文的复刻。

## 避免退化

- 只有品牌和口号，没有铺垫或节奏：读者没有预期可被改变。
- 拼很多热梗：注意力被分散，最后一句缺少一个明确的落点。
- 苦情一直写到结尾：读者只感到情绪负担；应及时用荒诞或小诉求卸掉重量。
- 反复沿用同一个收尾句、同一段失恋情节：只换名字，笑点没有变化。
- 转折后又解释“其实我就是想吃肯德基”：多出来的说明削弱最后一拍。
